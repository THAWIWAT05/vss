GANG CONTROL FIVE M DAILY - V4 Attendance & Delivery Overview Update

อัปเดตจากโปรเจกต์ V4 PostgreSQL ที่ผู้ใช้อัปโหลด

ฟีเจอร์เพิ่ม:
1) หน้า ประวัติ: ภาพรวมการขาดรายสมาชิก นับเฉพาะสถานะ absent
   แสดงจำนวนครั้ง วันที่ รอบ และเวลาเช็กชื่อ รวมเวลาที่บันทึก/แก้ไขล่าสุด
2) หน้า ระบบส่งของ (แอดมิน): ช่องค้นหาชื่อสมาชิก กรองทั้งตารางภาพรวมยอดส่งและตารางรายสมาชิกในแต่ละรายการ
   เพิ่มตารางภาพรวมต่อสมาชิก แสดงจำนวนรายการ ยอดส่งแล้ว และยอดคงเหลือ
3) API attendanceHistory ส่งประวัติทั้งหมด ไม่ตัดเหลือ 500 แถว เพื่อให้ยอดขาดสะสมถูกต้อง

วิธีใช้:
- แตก ZIP และนำโฟลเดอร์ GANG_CONTROL_DAILY ไปแทนโปรเจกต์เดิม
- คงค่า .env ของคุณไว้เอง (ห้ามนำ .env ขึ้น GitHub)
- npm install
- npm start
- บน Render: commit/push แล้วรอ deploy

หมายเหตุ:
- ขาด 1 ครั้ง = แถวเช็กชื่อหนึ่งรอบที่สถานะ absent; สถานะลา/ติดธุระ/มา/มาสายไม่นับ
- เวลาในรายงานคือเวลารอบเช็กชื่อที่กำหนด (16:30, 20:30, 23:50) และแสดงเวลา timestamp ที่บันทึก/แก้ไขด้วย
- ตรวจสอบ syntax ด้วย node --check แล้ว แต่ยังไม่ได้ทดสอบเชื่อมต่อ PostgreSQL ของผู้ใช้จริง
